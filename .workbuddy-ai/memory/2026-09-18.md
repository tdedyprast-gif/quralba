## Production Deployment Package

User meminta deploy aplikasi ke VPS dengan domain quralba.dwijacode.my.id. Setelah klarifikasi:
- Backend = Go 1.22 + Fiber (bukan FastAPI/Node), port 8004
- Frontend = React 18 + Vite (bukan CRA), VITE_API_URL kosong (relative URL)
- Deploy via **Cloudflare Tunnel** (bukan Nginx + Let's Encrypt di VPS)
- Folder legacy `backend/`, `frontend/`, `tests/` di root boleh dihapus

### Cleanup
- Dihapus: `backend/` (Python FastAPI), `frontend/` (React CRA), `tests/`, `test_reports/`, `test_result.md`, `memory/PRD.md`, `build.log`
- `.dockerignore` root + per-service dibuat

### Dockerfile
- `backend/Dockerfile.prod` — multi-stage Go → alpine, non-root (UID 1000), healthcheck /api/health, port 8004
- `frontend/Dockerfile.prod` — multi-stage Vite → nginx:alpine, gzip, SPA fallback, reverse proxy /api/ → backend:8004
- `backend/Dockerfile.dev` — CompileDaemon hot reload, Delve debug port 2345
- `frontend/Dockerfile.dev` — Vite dev server HMR, port 5173

### docker-compose
- `docker-compose.prod.yml` — db (internal only), backend (internal only), frontend (127.0.0.1:3000 saja). Backend tidak expose ke publik, hanya via internal Docker network. Logging terbatas (json-file, max 10m x 3).
- `docker-compose.dev.yml` — db expose 5432, backend hot reload + 2345, frontend Vite dev 5173 + HMR 24678, bind mount source code.

### Environment
- `.env.production` — template dengan placeholder jelas, JWT_SECRET & passwords WAJIB diganti
- `VITE_API_URL` kosong → frontend pakai relative URL via Nginx reverse proxy

### Cloudflare Tunnel
- `deploy/cloudflared-config.yml` — tunnel config, route ke localhost:3000
- `deploy/qurban-tunnel.service` — systemd service untuk auto-start
- SSL otomatis, DDoS protection, tidak perlu expose port 80/443

### Automation
- `deploy/deploy.sh` — script otomatis: cek .env → git pull (opsional) → build → start → wait DB → health check → cleanup → tunnel check
- `deploy/backup.sh` — backup DB + uploads, dengan retention policy, siap untuk cron
- `deploy/DEPLOY.md` — step-by-step lengkap dari clone sampai running
- `deploy/CHECKLIST.md` — 25+ item verifikasi post-deploy

### CI/CD (GitHub Actions)
- `.github/workflows/ci.yml` — diperbarui: hapus job legacy (Python/CRA), build pakai `Dockerfile.prod`, integration test via `docker-compose.yml`
- `.github/workflows/deploy.yml` — diperbarui: build & push `Dockerfile.prod` ke GHCR, rolling deploy ke VPS via SSH, health check post-deploy
